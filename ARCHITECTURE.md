# OpenRoots implementation contract

Original Classical Arabic research app; do not copy Ghareeb assets/code/identity. Monorepo npm workspaces: apps/mobile, apps/worker, packages/shared; Python ingestion in tools/ingest. User specification retained in docs/REQUIREMENTS.txt. No push/deploy without user approval. Use Expo SDK 58 stable verified npm 58.0.22; dependencies selected via expo install. Native AI must use development builds, not Expo Go. Do not claim native device or real cloud inference tests without execution.

## Shared public contract (all collaborators implement against this)
`packages/shared/src/index.ts` exports:
- `SourcePassage`: `{ id:string; entryId:string; bookId:string; bookTitle:string; author:string; headword:string; root:string|null; text:string; sourceUrl:string; license:string; locator:string|null }`
- `AIOptions`: `{ mode?:'concise'|'detailed'; task?:'explain'|'compare'|'translate'; signal?:AbortSignal; onToken?:(token:string)=>void; model?:string; history?:Array<{role:'user'|'assistant';content:string}> }`
- `AISection`: `{title:string; text:string; citations:string[]}`
- `AIAnswer`: `{ sections:AISection[]; insufficientEvidence:boolean; provider:'cloud'|'local'; model:string }`
- `AIProvider`: `{ generate(question:string, passages:SourcePassage[], options?:AIOptions):Promise<AIAnswer> }`
- `normalizeArabic(text:string):string`, `buildMessages(question,passages,options)`, `parseAnswer(raw:string,passages:SourcePassage[],provider:'cloud'|'local',model:string):AIAnswer`; strict citation validation, reject unknown IDs, no fabricated quote/locators.
Package name `@openroots/shared`, source TS exports.

## Dictionary SQLite contract
Bundled `apps/mobile/assets/dictionaries/openroots.db` generated by Python, not mock data.
`books(id TEXT PRIMARY KEY,title TEXT,author TEXT,source_url TEXT,license TEXT,edition TEXT,category TEXT)`
`entries(id TEXT PRIMARY KEY,book_id TEXT,headword TEXT,root TEXT,normalized_headword TEXT,normalized_root TEXT,text TEXT,source_url TEXT,locator TEXT)`
`passages(id TEXT PRIMARY KEY,entry_id TEXT,book_id TEXT,headword TEXT,root TEXT,text TEXT,normalized_text TEXT,ordinal INTEGER)`
`passages_fts` FTS5 virtual table `(passage_id UNINDEXED, headword, normalized_text)`; no triggers required, immutable dictionary.
Metadata in `apps/mobile/assets/dictionaries/manifest.json`: `{version:string,books:Array<{id,title,author,license,sourceUrl,entryCount,passageCount}>,entryCount:number,passageCount:number}`.
Stable SHA-based IDs; original text preserved. Only verified redistribution-compatible material bundled; OpenITI NC-SA skipped by default. Practical full dictionary if feasible; test requested ten words on actual data.

## Mobile adapters
`apps/mobile/src/ai/local.ts`: export `LocalAIProvider` implementing shared interface. Constructor no required args, uses singleton model manager. Never cloud calls here.
`apps/mobile/src/ai/models.ts`: export `modelManager` singleton exposing `getState():ModelState`, `subscribe(listener):()=>void`, `download():Promise<void>`, `pause():Promise<void>`, `load():Promise<void>`, `unload():Promise<void>`, `remove():Promise<void>`, `getStorage():Promise<{free:number,total:number}>`. Export `LOCAL_MODEL` with id,name,url,sha256,size,license; `ModelState` includes status ('absent'|'downloading'|'paused'|'verifying'|'ready'|'loading'|'loaded'|'error'), progress number 0..1, error:string|null. May expose additional fields. Integrity must be streaming/native, not multi-GB JS buffer. Pin known HF revision + checksum verified through API. Safe CPU default Android; Metal iOS.
`apps/mobile/src/ai/cloud.ts` mobile owner implements CloudflareAIProvider; endpoint POST /v1/generate with `{question,passages,model,mode,task,history,stream:false}` and Authorization bearer user access token; JSON AIAnswer. GET /v1/models authenticated returns `{models:Array<{id:string,available:boolean}>}`. SSE optional request stream true format document in worker README.

## Backend
Worker owner implements shared contracts and server. No hardcoded secrets, bearer auth configured via Wrangler secret ACCESS_TOKEN (>=32 chars). AI binding, rate limiter, free quota errors, deny absent credentials; model allowlist. Server responses validated. User-provided context untrusted. Explicit limits and timeout. No tokens in mobile environment examples.
